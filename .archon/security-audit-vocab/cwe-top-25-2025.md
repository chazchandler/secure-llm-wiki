# CWE Top 25:2025 — Auditor Reference

Source: <https://cwe.mitre.org/top25/archive/2025/2025_cwe_top25.html> — the **2025** MITRE CWE Top 25 Most Dangerous Software Weaknesses, ranked by exploitability, detectability, and impact score.
Staged into every audit run's KB at `$ARTIFACTS_DIR/kb/cwe-top-25.md` by the `kb-vuln-catalog` node.

Auditors MUST cite these canonical CWE ids in findings. The rank/score is a useful proxy for the finding's `severity` field — higher-ranked weaknesses tend to be higher-severity.

| Rank | CWE | Score | Name | Audit lens |
| ---: | --- | ---: | --- | --- |
| 1 | CWE-79 | 60.38 | Cross-Site Scripting (XSS) | Reflected/stored/DOM XSS — untrusted input rendered into HTML without contextual output encoding. |
| 2 | CWE-89 | 28.72 | SQL Injection | Untrusted input concatenated into SQL; prove source→sink, prefer parameterized queries. |
| 3 | CWE-352 | 13.64 | Cross-Site Request Forgery (CSRF) | State-changing actions without anti-CSRF tokens or same-site checks. |
| 4 | CWE-862 | 13.28 | Missing Authorization | Authenticated-but-unauthorized access; authz check absent on a privileged action. |
| 5 | CWE-787 | 12.68 | Out-of-bounds Write | Memory writes past buffer bounds (C/C++/unsafe) — the #1 KEV root cause. |

---

**Mapping to OWASP Top 10:2025** (see `owasp-top-25.md`): CWE-79/89/78/94/77 → A05 Injection; CWE-862/863/284/639/306 → A01 Broken Access Control; CWE-787/22/416/125/120/121/122 → A05 (injection of memory) + A03/A08 supply/integrity in unsafe codebases; CWE-502/77/94 → A05/A08.

**How auditors should use this:** cite the CWE id verbatim in each finding's `cwe` field (e.g. `CWE-89`). When the weakness spans multiple CWEs, pick the most-specific Top-25 id; add the rest in the `evidence`/`recommendation`. Use the rank as a sanity check on the `severity` you assign — a confirmed rank-1 XSS in a reachable surface is not "low".
